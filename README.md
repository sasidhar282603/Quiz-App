# Quiz App

## Description
A responsive Quiz App built using HTML, CSS, and JavaScript.

## Features
- Multiple-choice questions
- Instant answer feedback
- Score calculation
- Play Again option
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download the project.
2. Open `index.html` in a web browser.
3. Start answering the quiz questions.
